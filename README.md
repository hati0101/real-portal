# REAL 회원 홈페이지

Cloudflare Pages에 제공하는 로그인·회원가입·계정 복구 화면입니다. GitHub `main` 브랜치 변경으로 업데이트합니다.

공지와 다운로드 정보는 기존 게임 계정을 확인하는 HTTPS API에서 받아 표시합니다. 신규 가입은 기본적으로 닫혀 있으며 운영자 계정으로 접수 여부를 변경합니다.

프레임워크와 빌드 과정이 없는 정적 사이트이며 저장소 루트가 배포 대상입니다. 브라우저의 실제 높이에 따라 데스크톱 여백을 조정하고 모바일 화면에도 대응합니다.

이 저장소에는 서버 코드, 데이터베이스 접속 정보, 회원 정보 또는 비밀키를 저장하지 않습니다.
