# REAL 회원 홈페이지

Cloudflare Pages에 제공하는 로그인·회원가입·계정 복구 화면입니다. GitHub `main` 브랜치 변경으로 업데이트합니다.

공지와 다운로드 정보는 기존 게임 계정을 확인하는 HTTPS API에서 받아 표시합니다. 신규 가입은 기본적으로 닫혀 있으며 운영자 계정으로 접수 여부를 변경합니다.

프레임워크와 빌드 과정이 없는 정적 사이트이며 저장소 루트가 배포 대상입니다. 브라우저의 실제 높이에 따라 데스크톱 여백을 조정하고 모바일 화면에도 대응합니다.

이 저장소에는 서버 코드, 데이터베이스 접속 정보, 회원 정보 또는 비밀키를 저장하지 않습니다.

회원 메인은 양피지와 숲색을 사용한 게시판 형태입니다. 공지사항·패치노트·개발현황·자유게시판·문의·건의를 중단 탭에 모았습니다. 탭은 같은 화면의 `#notices`, `#patchnotes`, `#development`, `#community`, `#support`로 이동하며, 페이지 새로고침 없이 뒤로·앞으로 이동과 직접 주소 진입을 지원합니다.

회원은 자신의 게시글과 댓글을 관리하고 운영자는 삭제·고정을 할 수 있습니다. 새 문의·건의와 댓글은 다른 회원도 볼 수 있는 공개 게시판에 작성합니다. 이전 비공개 문의와 답변은 작성자와 운영자만 볼 수 있도록 기존 문의 창구에 남아 있습니다. 새 댓글 알림과 작성자 닉네임은 인증된 API에서 받아 표시합니다.

채팅은 로그인 후 홈페이지가 열리면 자동으로 연결됩니다. 최소화·복원, 크게 보기·이전 크기, 제목 영역 드래그와 방향키 이동을 지원하며, 게시판 탭을 바꾸거나 채팅창을 최소화해도 연결을 유지합니다.
